# Mobile Shooter

Jogo de tiro para celular em HTML5, CSS e JavaScript.

## Como executar

1. Abra o arquivo `index.html` em um navegador.
2. Para celular, use os botões touch na parte inferior da tela.
3. Você também pode testar com teclado no desktop:
   - `A` / `←` para esquerda
   - `D` / `→` para direita
   - `Espaço` / `W` / `S` para atirar

## Objetivo

Desvie dos inimigos e atire o máximo que puder para aumentar a pontuação.

## Arquivos

- `index.html`
- `style.css`
- `script.js`

## Observação

Este projeto foi pensado para funcionar como jogo simples de navegador, compatível com celulares e desktop.
